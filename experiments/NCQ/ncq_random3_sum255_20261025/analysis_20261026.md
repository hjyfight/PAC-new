# 五组无截断随机色板实验分析与作者复现建议

日期：2026-10-26（Asia/Shanghai）。分析目录：`experiments/NCQ/ncq_random3_sum255_20261025`。

## 结论

新五组实验支持更明确但仍有限定范围的结论：在当前六模型 INRIA 白盒协议下，使用无截断连续线性换色，保留 AdvPatch 的空间 RGB 权重比完整像素置换保留更多攻击能力。固定结构换成随机色板的平均 mAP50 代价为 +6.02 点；同一随机色板下完整像素置换的配对代价为 +49.89 点。颜色仍有影响，尤其是 YOLOv2，不能声称任意换色都保持攻击能力。

## 数据与独立核验

- 完整测试集 288 张、589 个人体框，输入 640×640，补丁张量 300×300，覆盖人体框面积 25%，测试无 EOT。
- 六模型各复用自己原来的单个 AdvPatch donor，不新增优化；每组色板在六个模型上共用。
- 60 项新攻击评估和 6 项 clean 重放完成；独立读取并核验 66 份原始 metrics.json，与汇总 mAP50/ASR 一致。
- 核对 60 张补丁哈希、132 份原基线指标哈希；六项 clean 的 mAP50、ASR 分子分母及逐 GT 检出记录与原实验完全一致。
- 60 张补丁的生成审计均为 float64/float32 越界比例 0、clamp 改变分量数 0；30 张打乱补丁与相应原输出的完整 RGB 向量置换严格相等。
- 独立复算均值、样本标准差及配对结构效应，均与现有 summary.json 一致。未重新运行模型推理或训练。

## 相对旧实验的变化与模型差异

新随机色板的保留结构均值从 42.23 降至 33.39，下降 8.84 点；相对 Bc1 的换色代价从 +14.86 降至 +6.02。新旧采样分布也发生改变，所以不能把 8.84 点全部归因于去掉截断，不能将其当作固定同一色板的 clamp 开关实验。

- YOLOv2 仍有明显色板敏感性：48.83 ± 14.49，相对 Bc1 +20.63；单组结果在 27.92–64.17 之间。其余五模型的平均换色代价为 +3.10。这是报告异质性的补充，不应从主结果中剔除 YOLOv2。
- YOLOv4 与 YOLOv5m 的平均换色代价仅 +1.28 和 +0.81；该结果是接近，未做等效性检验，不能称为统计等效。
- YOLOv5s 是打乱后仍有颜色效应的例子：打乱/Bc1 为 57.28，打乱/新随机为 66.39，差 +9.11；其新色板配对结构代价 +23.97，明显低于其他模型。不能把六模型均值解释成每个模型都对颜色不敏感，或打乱后攻击完全消失。
- 新色板并非对每个模型都优于旧色板：YOLOv5m 从旧随机 25.46 升至新随机 28.93。
- ASR 的六模型平均也支持结构结果：Bc1 72.85%，保留/新随机 65.10 ± 4.77%，打乱/新随机 7.05%。这里是各模型条件 ASR 的等权平均，非合并所有模型 GT 后的单一比率。

## 作者建议、通道和与截断

作者给出的实现是把原 AdvPatch RGB 通道作为未归一化权重。若原 8-bit 像素为 x，基色矩阵 C 的每行为一种颜色，则：

`w_k = x_k / 255; y_c = sum_k w_k C[k,c]`。

代码中的张量 x 已在 [0,1]，因此直接作为 w 使用；色板再除以 255 得到 [0,1] 输出。不应再把已经归一化的张量除以 255，也不应额外对三个权重做 softmax 或归一化，否则改变作者的算法。

以 [128,64,255] 为例，权重是 [128/255,64/255,1]，和约 1.753，所以它们是连续混合权重，不是严格的概率分布，也不是凸组合系数。

### “和为 255”的准确含义

新实验约束是每个输出通道沿三种基色求和：

`R1+R2+R3 = G1+G2+G3 = B1+B2+B3 = 255`。

这是矩阵列和约束，并非要求每个颜色自身的 R+G+B=255。例如 seed 0 三个颜色自身的 RGB 和为 236、76、453，但列和均为 255。

因为 0≤w_k≤1 且 C 非负，列和为 255 可保证 0≤y_c≤255，所以不需要实际截断。列和≤255 也足以保证不越界；取等号还保持共同灰度分量：原像素 [a,a,a] 在换色后仍为 [a,a,a]。这不代表任意彩色像素的亮度或局部对比度都不变。

### 固定 P1/P2 与随机色板应分别处理

- 复现 PAC-P1/P2：必须使用作者指定 Bc1/Bc2 的原值。当前代码 Bc1 为 [[119,49,72],[2,204,1],[134,2,182]]，Bc2 为 [[199,21,131],[40,165,4],[16,69,120]]，二者列和本来都是 [255,255,255]。保留现有 clamp 作边界保护即可；对合法 donor 它不改变结果，无需再加归一化或修改色板。
- 任意随机色板：clamp 可以使像素合法，但若生效，实际变换成为 clip(sum w_k C_k)，多了一步非线性饱和。donor 权重文件虽然没改，输出局部对比度和细节却可能被截断改变，因此不能仅用截断解释为严格的连续线性换色控制。
- 用于回应颜色与结构消融：建议新五组无截断、列和匹配 Bc1/Bc2 的色板作为主表，旧任意 RGB+clamp 作为补充敏感性结果。列和约束是为了实验可解释性选择的控制设计，不是作者这段文字明确规定的通用必要条件。

即使不截断，换色也只能严格保证“空间权重场和像素位置保持不变”。新的基色组合仍可改变可见纹理对比度、颜色、亮度，以及不同通道承载的信息；不能保证最终视觉图案或攻击性能完全不变。

## 论文与审稿回复建议

这组补充正面处理了旧随机色板的饱和混杂，强化了 F1 的干预实验解释；M9 的 NCQ 对比结论仍保持原样，没有新增 NCQ 评估。它不能补上训练种子方差、块级置换、真实环境色板、物理实验或其他方法/性能矛盾。

建议表述：

> 在统一的 INRIA 六检测器白盒协议下，复用 AdvPatch 的空间 RGB 权重并进行无截断连续基色混合，可以在所测试的五组随机色板上保留较强攻击能力。相对固定 Bc1，随机换色使六模型平均 mAP50 上升 6.02 个百分点；在同一随机色板下，完整像素置换使其上升 49.89 个百分点。因此，本协议中的完整结构置换造成的平均退化大于所测试的色板替换，且颜色敏感性依赖模型与色板。该实验不证明颜色无关、任意换色均有效，或学习了新的概率矩阵。
